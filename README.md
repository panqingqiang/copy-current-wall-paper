# Copy Current Wallpaper

这是一个简单的开源项目，旨在帮助用户快速复制当前桌面壁纸到指定位置或进行其他相关操作。该项目由 PowerShell 脚本组成，适用于 Windows 操作系统。

## 功能特性

- 快速获取当前桌面壁纸路径。
- 支持将当前壁纸复制到指定目录。
- 简单易用，适合自动化任务或日常使用。

## 使用方法

1. 确保你的操作系统为 Windows，并已安装 PowerShell。
2. 下载 `copyCurrentWallPaper.ps1` 脚本文件。
3. 打开 PowerShell，运行脚本：
   ```powershell
   .\copyCurrentWallPaper.ps1
   ```
